# Transformación de Texto en Embeddings con TensorFlow

Laboratorio de la asignatura Procesamiento de Lenguaje Natural 
Especialización en Inteligencia Artificial - Universidad de Cundinamarca

## Descripción

Este repositorio contiene el notebook desarrollado en Google Colab para el laboratorio de transformación de texto en embeddings utilizando TensorFlow.

El ejercicio incluye:

- Definición de un conjunto de textos
- Vectorización con TextVectorization
- Generación de embeddings con la capa Embedding
- Cálculo de embeddings promedio 
- Análisis de similitud semántica mediante similitud coseno
- Visualización de resultados con mapa de calor
